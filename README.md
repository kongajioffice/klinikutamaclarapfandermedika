# Website Klinik Utama Clara Pfänder Medika

Website statis siap dipasang di GitHub Pages.

## Cara publikasi
1. Login ke https://github.com lalu pilih **New repository**.
2. Beri nama `klinik-clara-pfander-medika`, pilih **Public**, lalu **Create repository**.
3. Upload seluruh isi folder ini. Pastikan `index.html`, `style.css`, dan `script.js` berada di root repository; folder `assets` juga ikut diunggah.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main`, folder `/ (root)`, lalu klik **Save**.
7. Tunggu sampai GitHub menampilkan URL website di halaman Pages.
